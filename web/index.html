The port

  • Game port — the web port of the client itself: real splash screen (layout driven by the game's own splashscreen.xml), loading donut, city hub, error screen; 16 languages from the decoded .btp packs, audio mixer, extracted APK + fan-CDN DLC assets. Formerly index.html.

City viewer

  • City View (PixiJS) — the viewer: oblique 2.5D town rebuilt on PixiJS 8 (single renderer, no server needed). Textured terrain, extracted building / character art, bsv3 anims, road-network experiments, street-verdict tooling (PHP for verdict persistence). All future viewer work happens here.
  • City View (legacy) — original Canvas2D / hybrid-WebGL page. Deprecated; kept only as an implementation reference.
  • Spec View — road-layout ground truth: renders only the saved cell grid from road-spec.json (no terrain data), same camera as City View. Nibble cells show the footpath / carriageway composition, 'P' cells uniform pavement; hover readout + legend for eyeballing alignment against the viewer. Data regenerated by tools/gen_spec_view_data.py.
  • Road Lab — footpath / carriageway tuning sandbox: enlarged N-S, E-W and pavement examples with per-side width steppers, presets, tone steppers and a 2:1 iso view; emits a copy/pasteable ROAD_ART reference block used to tune the road art above. Self-contained (no data or camera deps).

RE workbenches

  • Map Explorer — interactive map of the decoded city save (buildings, characters, streets, evidence).
  • CDN Explorer — format-RE workbench over the CDN file index (findings, format registry, bundle trees).
  • Asset Explorer — browses the extracted manifest: images, thumbs, audio, fonts, i18n.
  • Byte Map — byte allocation of the decoded Data.LandMessage .pb, coloured by RE status.

Project tracking

  • Progress dashboard (PHP) — completeness meters with snapshot deltas + sparklines across six sections, bundle coverage grid, session journal. Scanned by tools/progress_scan.py.
  • Task & decision board (PHP) — the live queue of pending tasks, user decisions and milestones, split out of the dashboard into tasks/. Guide: notes/07-progress-board.md.
