The rule the viewer applies today (notes/13 §6, §8): the four directions are the engine's four unit tile steps, which draw as 2:1 diagonals — up-left north, up-right east, down-right south, down-left west. Family = screen dy < 0 ? back : front; side = screen dx < 0 ? left : right; then the shipped PriorityList order — the authored side cell, drawn exactly as authored, then the plain cycle of the same family, then the other family. On the two steps a flat-authored crowd skin has no art for, the plain cycle is mirrored: (back && right) || (front && left), i.e. east and west. That last part is a ruling from this page, not a finding — the lean column says these cycles are square-on (homer −2.0 px, well inside the ±12 px band), so nothing in the pixels picks a side. It is also only a stand-in: a skin that ships its own _left/ _right art plays it unflipped. Unchecking the box takes any cell back to how it was drawn.
